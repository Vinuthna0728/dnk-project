# Dak Ghar Niryat Kendra – Backend API

Backend API for the Dak Ghar Niryat Kendra platform

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Pydantic
- JWT Authentication
- ReportLab

## Backend Features

- User authentication and authorization
- Buyer and seller management
- Order management
- Escrow management
- UPI/payment-related integration
- Compliance management
- Postal scan webhook processing
- Shipping event tracking
- CN23 document generation
- Database integration
- API testing and validation

## Main API Modules

- Authentication
- Orders
- Escrow
- Compliance
- UPI
- Postal Scan Webhook
- Shipping Events
- CN23 Generation
